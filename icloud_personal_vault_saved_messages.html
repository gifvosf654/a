কিভাবে Vercel-এ হোস্ট করবেন? (How to Deploy on Vercel)

  1. আপনার কম্পিউটারে বা ফোনে একটি ফোল্ডার তৈরি করে এই কোডটি index.html নামে সেভ করুন।
  2. Vercel.com-এ লগইন করে "Add New" → "Project" বা সরাসরি GitHub রিপোজিটরিতে index.html আপলোড করে Deploy করুন।
  3. যেকোনো ডিভাইস থেকেও যেন সকল মেসেজ ও ফাইল সবসময় সিঙ্ক থাকে, সেজন্য নিচে আপনার নিজের ফ্রি Firebase Config পেস্ট করে সেভ করতে পারেন (অথবা এই ব্রাউজারে স্বয়ংক্রিয়ভাবে সব ইতিহাস IndexedDB ও ক্লাউডে সেভ হয়ে থাকবে)।
